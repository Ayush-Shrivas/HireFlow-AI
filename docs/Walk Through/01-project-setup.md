# Project Setup

1. In Command Prompt, use `cd /d "E:\Final Project\HireFlow AI\backend"` when changing to the project drive.
2. Install backend dependencies from `backend/requirements/development.txt`.
3. Install frontend dependencies with `npm install` inside `frontend/`.
4. Run Django migrations from `backend/`.
5. Start Django, FastAPI, and React in separate terminals.
6. Use the SQLite fallback for Day 1 if PostgreSQL is not installed.

Docker is optional and is not required for daily development.

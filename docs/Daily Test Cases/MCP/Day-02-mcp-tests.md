# Day 2 MCP / Desktop Test Record

## Manual verification checklist

1. Start Django and the frontend using the local-development walkthrough.
2. Register or log in as a candidate.
3. Open the dashboard and confirm the marketplace section renders.
4. Search for a job title or skill and confirm the list updates.
5. Log in as a recruiter and create a company.
6. Confirm the creator is added as the company owner.
7. Create a draft job with one or more skills.
8. Publish the job and confirm it appears to candidates.
9. Confirm a non-member recruiter cannot create or modify that company’s jobs.
10. Confirm a candidate can update only the candidate profile endpoint.

## Status

The frontend production build and component tests passed. Full browser interaction was not recorded with Playwright on Day 2; the manual checklist is retained for local desktop verification.

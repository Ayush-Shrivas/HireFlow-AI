# Day 6 MCP / Manual Test Record

## Manual verification checklist

- Recruiter schedules an interview for an owned-company application.
- Candidate sees the interview and notification.
- Conversation participants can send and read messages.
- Non-participants cannot retrieve messages.
- Notifications and messages can be marked read.
- Dashboard metrics change only within the caller’s scope.

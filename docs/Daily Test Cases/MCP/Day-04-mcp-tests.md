# Day 4 MCP / Manual Test Record

## Manual verification checklist

- Candidate can upload a supported resume.
- Resume status and analysis can be retrieved by the owner.
- Recruiter cannot upload or view candidate resume data.
- Empty, oversized, and executable files are rejected.
- AI service unavailable fallback stores a safe pending analysis.
